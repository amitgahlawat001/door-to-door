# Door-to-Door Brand Guidelines

## 1. Positioning
Use the working brand concept: **Door-to-Door — Moving What Matters.**

Core ideas:
- Fast
- Reliable
- Transparent
- Connected
- Human
- Technology-enabled

The visual identity should feel like a premium logistics technology company, not a generic courier template.

## 2. Working palette
These are recommended starting tokens. Replace them with the company's actual brand colors if already defined.

- Ink / text: `#0B1B2B`
- Deep background: `#08131F`
- Accent blue: `#1479FF`
- Accent orange: `#FF7A00`
- White: `#F7FAFC`
- Muted text: `#6B7785`
- Soft background: `#EEF3F7`

Keep orange as an accent, not the dominant page color.

## 3. Typography
Recommended:
- Display: Inter Tight / Geist / Manrope-style grotesk
- Body: Inter / Geist Sans

Use one display family + one body family maximum.

Hero:
- 64–110px desktop, clamp down responsively
- tight tracking
- short lines
- 1–3 emphasized words per headline

Body:
- 16–20px
- 1.5–1.7 line-height

## 4. Visual language
Use:
- cinematic photography
- dark editorial panels
- clean white sections
- thin route lines
- small data labels
- oversized numbers
- sparse cards
- strong whitespace
- subtle grain/noise

Avoid:
- excessive glassmorphism
- generic purple gradients
- stock-photo grids everywhere
- excessive rounded cards
- bouncing animations
- every-element-on-scroll animation
