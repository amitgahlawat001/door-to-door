# Project Summary: Door-to-Door

## Overview

This project is a MERN stack application named "Door-to-Door". It is a web application built using React for the frontend.

## Tech Stack

- **Frontend Framework**: React (Create React App)
- **State Management**: Redux Toolkit
- **Backend**: Node.js / Express (Inferred from project path and dependencies)
- **Database**: MongoDB (Inferred from MERN stack naming)

## Current Status

- **Internationalization (i18n)**: The project is currently being updated to support multiple languages: English, Hindi, and Gujarati. Some pages have been converted, and work is ongoing to convert the remaining text.

## Project Structure

- `src/`: Source code for the React application.
- `pages/`: Application pages.
  - `Home.tsx`
  - `PageNotFound.tsx`
  - `Services.tsx`
  - `Tracking.tsx`
- `redux/`: State management.
  - `servicesSlice.ts`
  - `store.ts`
  - `testimonialsSlice.ts`
- `public/`: Static assets.
- `node_modules/`: Project dependencies.

## Coding Conventions

- **Component Style**: Functional components with Hooks.
- **State**: Redux Toolkit for global state management.
